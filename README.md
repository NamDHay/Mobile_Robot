# Mobile_Robot
Capstone Project: Design and Development of a Mobile Robot for Information Promotion and Document Delivery at Exhibition Booths and Museums.

Developed an autonomous mobile robot using LiDAR (A1M8), RGB-D camera (Intel RealSense D435), and wheel odometry to build 2D/3D maps with RTAB-Map SLAM. Implemented Dijkstra for global path planning and DWA for real-time obstacle avoidance. Integrated a Vietnamese-language voice-enabled chatbot for interactive event information and natural user interaction.
